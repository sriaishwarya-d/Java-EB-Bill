Java EB Bill Calculator

A simple Java program that calculates electricity bills for domestic and commercial connections based on the number of units consumed.

Features
Supports domestic electricity connections
Supports commercial electricity connections
Accepts units consumed as input
Calculates the bill based on different unit ranges
Displays the total amount to be paid
Concepts Used
Classes and Objects
Methods
Scanner for user input
Conditional Statements
If-else statements
Basic arithmetic operations
How It Works

The program uses a billCalc class with separate methods for calculating domestic and commercial electricity bills. The user selects the connection type and enters the number of units consumed. The program then calculates and displays the amount to be paid.

For a domestic connection, different rates are applied based on the units consumed. A separate calculation is used for commercial connections.

Connection Types
1. Domestic
2. Commercial
How to Run
Make sure Java is installed on your computer.
Open a terminal in the project folder.
Compile the program:
javac EB_bill.java
Run the program:
java EB_bill
Enter the connection type and units consumed.
